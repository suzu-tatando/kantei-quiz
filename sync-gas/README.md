# 自動同期の設定手順（Googleスプレッドシート）

iPhone と iPad の正誤記録を自動で同期するための設定です。所要時間は10分ほどで、
1回設定すれば以降は解答するたびに自動で同期されます。

## 1. スプレッドシートを作る

1. [Googleドライブ](https://drive.google.com/) を開く
2. 「新規」→「Googleスプレッドシート」を作成
3. 名前を「暗記チェックブック 記録」など分かりやすいものに変更

## 2. スクリプトを貼り付ける

1. そのスプレッドシートのメニューから **拡張機能 → Apps Script** を開く
2. 最初から入っている `function myFunction() {}` を**すべて消す**
3. このフォルダの [`Code.gs`](Code.gs) の中身を**すべてコピーして貼り付ける**
4. 先頭にある次の行の `CHANGE-ME` を、**自分だけの合言葉**に書き換える

   ```js
   var SECRET = 'CHANGE-ME';
   ```

   例：`var SECRET = 'kantei2026-abcd';`
   （英数字で12文字以上を推奨。これがURLを知られたときの防御になります）

5. 保存（フロッピーのアイコン、または ⌘S）

## 3. ウェブアプリとして公開する

1. 右上の **デプロイ → 新しいデプロイ**
2. 歯車アイコン →「**ウェブアプリ**」を選ぶ
3. 次のとおり設定する
   - 説明：任意（例「暗記チェックブック同期」）
   - **次のユーザーとして実行：自分**
   - **アクセスできるユーザー：全員**
4. 「デプロイ」を押す
5. 初回は承認を求められる
   - 「アクセスを承認」→ 自分のGoogleアカウントを選択
   - 「このアプリは確認されていません」と出たら、**詳細** →「（プロジェクト名）に移動」→「許可」
6. 表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/……/exec`）をコピー

## 4. アプリ側に入力する

iPhone と iPad の**両方**で同じ作業を行います。

1. アプリを開き、ホームの「端末間で記録を共有」を押す
2. 「自動同期（Googleスプレッドシート）」に
   - **ウェブアプリのURL**（手順3でコピーしたもの）
   - **合言葉**（手順2で決めた `SECRET` と同じ文字列）

   を入力する
3. 「保存して同期」を押す → 「同期しました（N問）」と出れば完了

以降は、解答するたびに自動で送信され、アプリを開いたときと他のアプリから戻ったときに
最新の記録を取得します。ホーム画面に「最終同期 ○/○ ○○:○○」と表示されます。

## 記録の見え方

スプレッドシートの「記録」シートに次の形で保存されます。

| 問題 | 解答回数 | 直近の正誤 |
|---|---|---|
| Q1 | 3 | ✕✕○ |
| Q2 | 1 | ○ |

正誤は古い順に並びます（右端が最新）。手で書き換えても次回の同期に反映されます。

## 競合したときの扱い

同じ問題を両方の端末で解いた場合は、**通算の解答回数が多い方の記録**を採用します。
オフラインで解いた分は端末内に残り、次に通信できたときにまとめて送信されます。

## 記録をすべて消したいとき

自動同期を設定していると、ホームの「正誤の記録をリセット」は**すべての端末の記録を消去**します。

1. どちらかの端末で「正誤の記録をリセット」を押す
2. 確認に「OK」→ その端末とスプレッドシートの記録が消える
3. もう一方の端末は、**次にアプリを開いたとき**に自動で消去される

仕組みとしてスプレッドシートに「世代」の番号（E4セル）を持たせています。リセットのたびに
1つ増え、古い世代のままの端末は送信内容が採用されず、空の記録を受け取ります。
これにより、消したはずの記録が他の端末から復活することを防いでいます。

サーバーに接続できないときはリセットを実行せず、「この端末だけ消しますか」と確認します。

## うまくいかないとき

| 症状 | 対処 |
|---|---|
| 「合言葉が一致しません」 | `Code.gs` の `SECRET` とアプリに入れた合言葉が同じか確認。書き換えた後は**再デプロイ**が必要です |
| 「接続できませんでした」 | URLの末尾が `/exec` か（`/dev` ではない）、アクセス権が「全員」か確認 |
| スクリプトを直したのに反映されない | **デプロイ → デプロイを管理 → 編集（鉛筆）→ バージョン「新バージョン」→ デプロイ** で更新してください |

## 安全性について

「アクセスできるユーザー：全員」で公開するため、URLを知られると読み書きされる可能性があります。
合言葉が一致しないリクエストは拒否されますので、**URLと合言葉をセットで他人に渡さない**ようにしてください。
万一漏れた場合は `SECRET` を変更して再デプロイし、各端末に入れ直せば無効化できます。
